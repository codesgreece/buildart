# BUILDART

Premium interactive website for BUILDART — construction & building products, Thessaloniki.

## Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- Framer Motion
- GSAP ScrollTrigger
- Lenis smooth scroll

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — serve production build
- `npm run lint` — ESLint

## Concept

The site itself is being built: hold-to-construct loader, scroll-driven assembly, interactive energy / climate / fireplace experiences, house configurator wired into the quote form, and a footer demolition easter egg.
